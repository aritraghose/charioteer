# Charioteer

Work in progress. Project details will be added once the app is built.

## Development

```sh
pnpm install
pnpm dev
```

The dev server runs at http://localhost:3000.

## Build

```sh
pnpm build
```

## Deploy

The app is hosted on Cloudflare Workers.

```sh
pnpm exec wrangler login
pnpm run deploy
```
